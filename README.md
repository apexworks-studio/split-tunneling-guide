# Раздельное туннелирование на Windows и Linux

Инструкции APEX WORKS: выбранные подключения через собственный VDS, остальные — напрямую.

- **Windows:** точечные IPv4-маршруты → tun2socks → Xray → VDS.
- **Linux:** приложения с поддержкой прокси → локальный Xray → VDS; разделение по правилам Xray.

## Что проверено

Синтаксическая проверка двух шаблонов через `xray run -test` выполнена на Xray 26.7.28 с временными тестовыми параметрами. Проверены PowerShell-скрипт, 7 блоков PowerShell-команд и 19 Bash-блоков, целостность ZIP. Проверка синтаксиса не подтверждает сетевое соединение: выполните проверки двух маршрутов из инструкции на своих устройствах.

Windows-пример ограничен выбранными IPv4-адресами и обновляет их при запуске. IPv6, DNS/DoH, UDP нужного приложения и автозапуск требуют отдельной проверки. Linux-пример не перехватывает автоматически трафик программ без поддержки прокси. Это не kill switch. Подробности и откат — в инструкциях.
